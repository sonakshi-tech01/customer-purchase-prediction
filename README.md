# customer-purchase-prediction
A Machine Learning project focused on predicting customer purchase behavior using Python and IBM Cognos.

## Project Overview

This project includes data cleaning, exploratory data analysis, data visualization, machine learning model development, and business intelligence dashboarding.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab
- IBM Cognos

## Project Workflow

1. Data Cleaning
2. Exploratory Data Analysis
3. Data Visualization
4. Machine Learning
5. Model Evaluation
6. IBM Cognos Dashboard

## Machine Learning Models

- Decision Tree
- Random Forest

## Model Performance

The project document reports a model accuracy of *87.72%*.

## Key Features

- Handled missing and invalid values
- Removed duplicate records
- Performed exploratory data analysis
- Created multiple visualizations
- Built classification models
- Evaluated model performance
- Created an IBM Cognos dashboard

## Project Files

- customer_purchase_prediction.ipynb — Python notebook containing the complete analysis and machine learning workflow.
