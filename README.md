# Customer Purchase Prediction

A Machine Learning project focused on predicting customer purchase behavior using Python and IBM Cognos.

## Project Overview

This project covers the complete workflow of customer purchase prediction, including data cleaning, exploratory data analysis, data visualization, predictive modeling, model evaluation, and business intelligence dashboarding.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab
- IBM Cognos

## Project Workflow

1. Data Cleaning
2. Exploratory Data Analysis (EDA)
3. Data Visualization
4. Machine Learning Model Development
5. Model Evaluation
6. IBM Cognos Dashboard

## Data Cleaning

The dataset was processed by:

- Handling missing and invalid values
- Replacing invalid values with missing values
- Handling age and income range issues
- Managing extreme outliers
- Filling numerical missing values using the median
- Removing duplicate records

## Exploratory Data Analysis

The project includes visualizations such as:

- Customer purchase distribution
- Histograms of numerical features
- Purchase rate by visits
- Time spent vs. loyalty points
- Box plots for numerical variables
- Correlation heatmap

## Machine Learning

Two classification approaches were explored:

- Decision Tree
- Random Forest

The project document reports a model accuracy of *87.72%*.

## Dashboard

An IBM Cognos-style dashboard was created to analyze:

- Customer purchase behavior
- Visits and purchase patterns
- Age and income analysis
- Customer engagement
- Numerical distributions
- Data quality and correlation
- Purchase prediction
- Decision Tree results
